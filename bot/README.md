# RDnet Telegram Bot

ربات دو‌زبانه مدیریت کاربران 3X-UI. اطلاعات حساس فقط در `/etc/rdnet-bot/env` نگهداری می‌شود.

## دستورات

- `/start` شروع و انتخاب زبان
- `/claimowner CODE` ثبت اولین مدیر
- `/admin` داشبورد مدیر
- `/vpnadmin` مدیریت دکمه‌ای V2Ray، L2TP و WireGuard
- `/requestlist` درخواست‌های باز

## مدیریت VPN از تلگرام

فقط Owner/Admin می‌تواند از منوی دکمه‌ای بات:

- اکانت V2Ray را با انتخاب دکمه‌ای حجم، مدت و تعداد دستگاه بسازد و QR/لینک سابسکریپشن تحویل بگیرد.
- کاربر L2TP بسازد یا حذف کند و وضعیت، مدت اتصال و مصرف را ببیند.
- کاربر WireGuard بسازد، QR و فایل کانفیگ بگیرد، حذف کند و آخرین handshake و مصرف تجمعی را ببیند.
- تمام عملیات مدیریتی در جدول audit ثبت می‌شوند.

بات با کاربر محدود اجرا می‌شود و فقط اجازه اجرای helper اعتبارسنجی‌شده VPN را از طریق sudo دارد؛ به تنظیمات Xray یا تونل خروجی دسترسی مدیریتی داده نمی‌شود.

کاربر برای اتصال امن اشتراک، `email UUID` را می‌فرستد. UUID ذخیره نمی‌شود.

## مدیریت سرویس

### پروکسی اختصاصی

قابلیت اختیاری `/proxyadmin` یا «پروکسی اختصاصی» در `/vpnadmin`: ساخت حساب با
نام، حجم دلخواه، سقف IP هم‌زمان و اکسس‌لیست؛ مشاهده مصرف، قطع دسترسی و
ساخت رمز جدید. نصب آن مستقل و فقط با تأیید مدیر است؛ [جزئیات](PROXY.md).

```bash
sudo systemctl status rdnet-bot
sudo journalctl -u rdnet-bot -f
sudo systemctl restart rdnet-bot
```
